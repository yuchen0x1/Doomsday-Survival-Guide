# v1.1.2 发布尝试记录

日期：2026-11-16。标签 `v1.1.2` 已推送，但没有创建正式 GitHub Release。

GitHub Actions 运行 [43881997910](https://github.com/yuchen0x1/Doomsday-Survival-Guide/actions/runs/43881997910) 中，Web 和 Android 构建成功，Windows 构建失败。

失败原因：`apps/desktop/src-tauri/Cargo.toml` 已更新到 `1.1.2`，但 `apps/desktop/src-tauri/Cargo.lock` 中桌面包仍为 `1.1.1`；Windows 工作流使用 `--locked`，因此拒绝生成新锁文件。

由于 Windows 失败，汇总和正式发布任务被跳过；本次没有可供下载的三端附件或 `SHA256SUMS`。修正后的锁文件和版本进入 [v1.1.3 三端发布](v1.1.3-platforms.md)。

## 构建与版本约束

- `scripts/verify-release-versions.cjs` 校验 Web、桌面、移动、Tauri、Cargo 与 Android 版本一致。
- `.github/workflows/release-all.yml` 分别构建 Web、Windows、Android，随后汇总并生成 `SHA256SUMS`。
- 本次失败不代表远程源码删除了 API/Tauri 文件；本地同步盘缺失的工作树文件没有作为远程删除提交。

## 当前验证边界

- 已完成本地 Web、核心包和知识数据的类型检查、测试与构建。
- 原生打包、签名和公开 Release 只在对应 GitHub Actions 成功并能读取公开附件后计为通过。
