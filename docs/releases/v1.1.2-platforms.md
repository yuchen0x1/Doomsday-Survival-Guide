# v1.1.2 三端发布

日期：2026-11-16。源码版本统一为 `1.1.2`，Android `versionCode=10102`。

正式附件位于 [v1.1.2 发布页](https://github.com/yuchen0x1/Doomsday-Survival-Guide/releases/tag/v1.1.2)。

| 平台        | 文件                                               | 使用方法                                                                                 |
| ----------- | -------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Web/PWA     | `apocalypse-survival-web-v1.1.2.tar.gz`            | 解压后用 HTTPS 或 localhost 托管，并配置 SPA 回退到 `index.html`。                       |
| Windows x64 | `apocalypse-survival-windows-x64-v1.1.2-setup.exe` | 运行安装程序。安装包包含 WebView2 离线安装组件；Windows 安装程序未做 Authenticode 签名。 |
| Android     | `apocalypse-survival-android-v1.1.2.apk`           | 下载到手机后安装；正式包沿用发布证书并通过 Actions 签名校验。                            |

`SHA256SUMS` 覆盖三个文件。下载到同一目录后，Linux/macOS 使用 `sha256sum -c SHA256SUMS`；Windows 使用 `Get-FileHash -Algorithm SHA256 <文件>` 对照。

## 构建与版本约束

- `scripts/verify-release-versions.cjs` 校验 Web、桌面、移动、Tauri、Cargo 与 Android 版本一致。
- `.github/workflows/release-all.yml` 分别构建 Web、Windows、Android，随后汇总并生成 `SHA256SUMS`。
- GitHub Actions、公开附件、哈希和平台验收结果以本页后续记录为准；本地同步盘缺失的 API/Tauri 工作树文件不作为远程删除提交。

## 当前验证边界

- 已完成本地 Web、核心包和知识数据的类型检查、测试与构建。
- 原生打包、签名和公开 Release 只在对应 GitHub Actions 成功并能读取公开附件后计为通过。
