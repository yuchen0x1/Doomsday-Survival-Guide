# 更新历史

## v1.1.0 · 2026-11-13

### 物资与备份

- 物资支持表单编辑、名称/分类/备注搜索，以及优先级、名称、到期日排序。
- 按实际库存差额生成补货清单并导出 CSV；达到最低库存后不再误报缺货。
- 修复连续调整数量时库存和流水不同步的问题，盘点调整也能查看记录。
- 三个备份入口统一提供恢复预览，损坏备份会明确报错；恢复失败不会留下半份数据。
- 清除本应用个人数据时，保留同一站点下其他应用的数据。

### 使用体验

- 阅读历史开关和紧凑排版生效，尚未接入的选项明确标注。
- 手机弹窗完整覆盖页面，键盘焦点保留在对话框内，关闭后回到原位置。
- 改善内部导航、离线知识检索、危险等级筛选和离线包数据一致性。

本版本提供可自行托管的 Web/PWA 压缩包与 SHA-256 校验文件，兼容已有版本 1 的本地备份。个人数据仍存于本机；网页使用 HTTPS 或 localhost 访问。此次未发布 Windows 安装器或 Android/iOS 安装包，WorkBuddy 历史 Demo 不会随 GitHub 发布自动更新。
