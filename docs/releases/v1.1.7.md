## 📢 版本概述

本次更新是安全与兼容性补丁：管理端修改已发布内容会自动退回草稿并重新审核；生产环境默认启用 CORS 白名单、关闭 Swagger，数据库异常时健康检查返回 503；AI 流式回答改为空闲超时，不再因总时长被截断。同时修复旧 WebView 崩溃、分类搜索越界和备份读取无上限等缺陷。

## 🔧 改进与优化

- **内容复审**：管理端 PATCH 修改已提交、已审核或已发布内容时，同一事务内退回 `draft`、清空审核人/审核时间并写入审核记录，必须重新走状态机才能发布。公开接口会立即停止返回该内容。
- **AI 流式超时**：`AI_TIMEOUT_MS` 对对话流改为两次数据之间的空闲超时，长回答只要持续输出就不会被固定总时长中断；图片识别仍使用总超时。
- **生产安全默认值**：CORS 仅使用 `CORS_ORIGINS` 白名单（`ENABLE_CORS_WHITELIST=false` 仅在 development/test 生效）；Swagger 在 production 默认关闭；新增 `TRUST_PROXY`，未设置时不信任 `X-Forwarded-For`。
- **健康检查**：数据库探测失败返回 HTTP 503，便于负载均衡摘除异常实例。
- **备份读取**：桌面端读取 JSON 备份前检查文件大小，超过 25 MB 直接拒绝，避免一次性读入超大文件。

## 🐛 问题修复

- **旧 WebView 崩溃**：物资流水页改用兼容写法，修复 Android 5.1 旧 WebView / 旧 Safari 不支持 `Array.prototype.toSorted` 导致的页面报错。
- **搜索类型计数**：全局搜索切换类型后不再丢失其他类型的筛选 chip 与计数。
- **分类内搜索**：在图鉴分类页搜索时只返回当前分类文章，不再越界到全库。
- **AI 超时误判**：持续输出的长回答不再被固定总时长截断。
- **死代码清理**：移除同步服务未使用的委托变量与认证服务未使用导入。

## 🔒 安全与兼容性

- **CORS 行为变化**：生产环境必须设置 `CORS_ORIGINS` 为实际前端域名；未配置时跨源浏览器请求会被拒绝，同源部署不受影响。
- **Swagger 默认关闭**：生产环境如需接口文档，显式设置 `ENABLE_SWAGGER=true`，并限制访问来源。
- **反向代理**：仅在可信代理后设置 `TRUST_PROXY`（如 `1` 或 `loopback`），否则限流与审计会按代理 IP 统计。
- **内容下线**：修改已发布内容会立即退回草稿并从公开接口消失，重新发布前请确认这是预期行为。
- 无数据库结构变更；覆盖安装保留本地数据。

| -------------------------------------------------- | -------------------- | ----------------------------------------------- |
| `apocalypse-survival-web-v1.1.7.tar.gz`            | Web / PWA            | 静态站点构建产物，解压后部署到 HTTPS 静态服务器 |

## 🔄 升级与数据迁移

- **兼容性**：支持从 1.1.x 直接覆盖升级，无需先卸载。
- **配置和数据**：收藏、历史、物资、笔记、学习记录和本地 AI 会话保存在本机 IndexedDB，覆盖安装不会删除；服务端无数据库结构变更。
- **部署配置**：升级 API 前请确认 `CORS_ORIGINS` 包含实际前端域名；位于反向代理后时设置 `TRUST_PROXY`。生产环境默认不再提供 `/api/docs`，需要时设置 `ENABLE_SWAGGER=true`。
- **回退方式**：可重新安装旧版安装包；回退前建议导出 JSON 备份。
