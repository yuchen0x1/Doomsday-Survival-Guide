## 📢 版本概述

本次更新修复桌面端 Rust 依赖安全漏洞，并把 RustSec 检查加入安全检查和发布流程。同时交付此前 v1.1.8 未发布的地图、收藏、AI 会话、离线包、更新检查和服务端隐私修复，改善手机导航显示。v1.1.8 的发布已取消，用户可从已发布的旧版本直接升级到本版本，无需安装中间版本。

## 🔧 改进与优化

- **更新检查恢复**：原生端离线启动后恢复联网或回到前台会补查；失败请求不再占用每日成功检查额度，最多每 5 分钟重试。Web/PWA 同样区分成功记录和失败尝试，异常或未来时间戳不再长期阻断更新。
- **离线包一致性**：离线数据和包元数据使用同一 IndexedDB 事务，写入失败保留上一版；升级时记录内置目标版本，避免更新后仍一直提示可更新。
- **手机布局与可访问性**：收紧窄屏顶栏的间距和控件宽度；为在线状态和 AI 入口补充辅助技术标签，手机底部 AI 标签使用正确的中英文文案。
- **模板清理**：删除两份无用的 Capacitor 示例测试，其中一份仍断言错误的默认包名；保留构建所需资源、锁文件和有引用的历史报告。

## 🐛 问题修复

- **地图坐标偏移**：瓦片、标记和点击坐标统一使用真实视野中心；修复南北箭头反向、极区投影、跨经线位置和宽屏瓦片覆盖问题。
- **重复收藏**：并发保存收藏使用同一读写事务检查和写入，界面同时去重。
- **AI 会话干扰**：新建或切换会话后，旧请求的回调和结束状态不再污染新会话；中文输入法组合输入时按 Enter 不再提前发送。
- **同步数据丢失**：覆盖同步前拒绝空值、非对象条目和格式错误的会话消息，避免跳过非法条目后静默清空已有数据。
- **异常恢复**：路由加载失败后切换到首页可恢复页面；离线包更新失败会明确提示旧包已保留；原生更新插件统一注册，消除重复注册警告。
- **手机导航标签**：修复底部 AI 页面入口错误显示为“搜索”或“Search”的问题。

## 🔒 安全与兼容性

- **Rust 依赖安全修复**：锁定 `cookie` 由 `0.18.2` 升至 `0.18.3`、`url` 由 `2.5.8` 升至 `2.5.9`，并同步将 `form_urlencoded` 由 `1.2.2` 升至 `1.2.3`，修复本轮发现的依赖漏洞。
- **发布安全门禁**：安全检查和三端发布流程加入基于 `cargo-audit 0.23.0` 的 RustSec 审计，依赖漏洞会阻止检查或发布继续，避免只检查 JavaScript 依赖而遗漏桌面 Rust 依赖。
- **审核并发保护**：编辑和状态转换写入同时校验内容版本与审核状态，交错请求返回 HTTP 409，防止旧审核结果发布已修改内容。
- **个人同步隐私**：`/sync/*` 审计只保留操作元数据和脱敏标记，不再复制档案、备注、位置或会话载荷；新增数据库迁移清理历史同步审计载荷。
- **旧版发现兼容**：沿用官方 `releases/latest` 接口、稳定版标签、安装包命名、应用标识和 Android 正式发布证书。v1.1.5 原生端通过设置手动检查；v1.1.6–v1.1.7 在联网启动时自动检查，也可手动检查。旧版离线启动后未收到提示时，请联网重启或手动检查。

## 📦 下载与安装

| 文件名 | 平台 / 架构 | 说明 |
| --- | --- | --- |
| `apocalypse-survival-web-v1.1.9.tar.gz` | Web / PWA | 静态站点资源，部署到 HTTPS 静态服务器 |
| `apocalypse-survival-windows-x64-v1.1.9-setup.exe` | Windows 10/11 x64 | NSIS 安装程序，未做 Authenticode 签名 |
| `apocalypse-survival-android-v1.1.9.apk` | Android / 通用 APK | 沿用正式发布证书的覆盖安装包 |
| `release-metadata.json` | 全部平台 | 文件名、平台、大小和 SHA-256 索引 |
| `SHA256SUMS` | 全部平台 | 三平台安装或部署文件及元数据的 SHA-256 摘要 |

- 首次安装：Web/PWA 部署静态包或访问在线站点；Windows 运行安装程序；Android 使用系统安装器安装 APK。详见[安装指南](https://github.com/yuchen0x1/Doomsday-Survival-Guide/blob/main/docs/INSTALL.md)。
- 已安装用户：Web/PWA 检测新资源后提示更新；Windows / Android 打开发行页下载同平台安装包，关闭应用后覆盖安装。不要先卸载。

## 🔄 升级与数据迁移

- **版本兼容**：可从已发布的旧版本直接覆盖升级，无需安装未发布的 v1.1.8。v1.1.0–v1.1.4 原生包不包含更新检查代码，需要手动下载覆盖安装一次，之后可使用新版更新检查。
- **本机数据**：沿用现有应用标识和 IndexedDB，覆盖安装保留收藏、历史、物资、笔记、学习记录与 AI 会话；升级前建议导出 JSON 备份。
- **服务端部署**：备份数据库后执行 `pnpm --filter @apocalypse/api exec prisma migrate deploy`，再部署 API。新增迁移只脱敏历史 `AuditLog.payload`，不删除个人数据业务表记录。
- **回退方式**：恢复上一套完整 Web 资源或同平台旧包前先备份；Android 降级受系统限制。回退应用版本不会恢复已经脱敏的历史审计载荷。

## 🧪 验证结果

- 本地 `pnpm test`：186 项通过（core 41、knowledge-data 10、API 64、Web 71），包括新增的中英文手机 AI 导航标签回归测试。
- 本地 `pnpm typecheck`、Web/PWA 生产构建、API 编译、Capacitor 归档兼容性和四平台版本对齐检查通过。`pnpm lint` 通过，仍报告已有 63 项 warning 和 9 项 info。
- `pnpm audit` 和生产依赖审计均未发现已知漏洞；`cargo-audit 0.23.0` 使用更新后的 RustSec 数据库检查实际锁文件，漏洞条目为 0，未添加忽略规则。
- 更新相关回归测试 14 项通过；使用 v1.1.5、v1.1.6、v1.1.7 的更新解析逻辑连接官方接口，确认仍能识别当前已发布的 v1.1.7。此项验证旧版接口兼容性，不等同于新版发布后的通知验收。
- 发布流程配置了 Web、Windows、Android 构建、Android 正式证书与安装包版本校验、附件下载后的 SHA-256 校验；实际发布结果以对应 GitHub Actions 和 Release 附件为准。
- 本次未执行真实 Windows / Android 设备覆盖安装，也未构建 iOS 安装包。

## ⚠️ 已知问题

- Rust 锁文件仍有 5 项上游维护状态警告，以及 Linux/BSD GUI 依赖 `glib` 的类型安全警告（`RUSTSEC-2024-0429`）。当前 Tauri/GTK3 依赖链没有兼容的补丁升级方案；已检查这些 GUI/桌面集成依赖不进入本次 Windows 安装包，Linux/BSD 桌面构建仍受此限制。
- v1.1.0–v1.1.4 原生包没有更新检查代码，必须手动下载覆盖安装；发布新版本无法给旧安装包补入提示逻辑。
- 原生端当前提示更新并打开官方发行页，不支持自动下载安装或静默更新。Windows 安装程序未做代码签名，可能出现 SmartScreen 提示。
- AI `tool_calls` 仍只展示，不回传工具执行结果；iOS、macOS 和 Linux 未提供本次原生安装包。
