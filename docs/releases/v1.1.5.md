## 版本概述

Windows 和 Android 设置页可检查稳定版并打开官方发行页。Web/PWA 可调整定期检查频率，暂时关闭更新提示后仍能在设置中应用已缓存的新版本。

## 改进

- 已保存的收藏、库存、笔记和学习记录会随原有本地数据库保留。覆盖安装前可以导出 JSON 备份。
- 自托管者可以用 Docker Compose 提供静态 Web/PWA。
- 自托管 API 的刷新会话改为一次性轮换。使用旧刷新会话时请重新登录，已有数据库记录可继续读取。生产模式需要单独设置至少 32 字符的 JWT 密钥。

## 下载与安装

- Web/PWA：下载 `.tar.gz` 后部署到静态服务器，或使用 GitHub Pages。
- Windows 10/11 x64：下载安装程序，关闭应用后覆盖安装。当前安装程序未做 Authenticode 签名。
- Android：使用系统安装器覆盖安装附带的 APK。APK 沿用正式签名。
- `SHA256SUMS` 提供下载文件摘要。文件名、平台、大小和更新方式见 `release-metadata.json`。
