## 发布流程

GitHub Actions 使用 Node 22.13 / pnpm 11；显式生成 Prisma 类型后执行 Lint、类型检查、测试和构建。Release 标签必须等于根 package.json 版本。Web 工件只打包 dist；SHA256SUMS 使用相对文件名，下载到同一目录即可验证。

GitHub Actions、Pages 与 Release 的最终状态以仓库对应运行和发布页为准；本文件记录本地结果及下方远程发布证据。源文件中的同步缺失项没有作为删除提交。

后端 vitest 升至 5.1.0，与 Web 测试工具一致，移除旧 tinypool / mocker 依赖链。ansi-regex 4/5 分别固定到 4.1.1 / 5.0.1。tar 升至 7.5.21，并通过 pnpm 补丁调整 Capacitor 6 模板解压的 CommonJS 导入；`node --test scripts/verify-capacitor-template.cjs` 验证真实归档创建/解压，加入 CI。以上属于构建/测试依赖维护，无新的用户可见功能。
