00使用说明

读之前先明确三件事：这份手册的边界、它假定的条件，以及它不会替你做的判断。

这本手册解决什么问题

它假定以下条件同时成立：全球互联网中断，蜂窝网络、卫星通信、云端服务全部不可用；没有外部救援的时间表；你手上只有一台还能开机的手机或电脑，以及其中预先保存的离线文件。场景是极寒环境（积雪、冰冻、低温风寒），或远古环境（没有金属制品、没有电力供应、没有现成建筑与工具），或两者叠加的冰河期式处境。

它不解决的问题：群体性灾难的政治与社会应对、长期工业化重建、传染病大流行防控。这些超出个人野外生存的范畴。

三条铁律

  1. 信息必须先于灾难存在。断网之后你下载不了任何东西。所有指望"到时候再查"的知识，等于不存在。
  2. 电力是信息的载体，按生命维持系统管理。设备不是玩具，是地图、是手册、是光源、是时间。电量的每一次消耗都要有理由。
  3. 关键知识必须有非电子备份。电子设备会没电、会进水、会冻到关机、会摔碎。真正救命的那几页，必须能写在纸上、刻在木头上、记在脑子里。

1.1 你手上其实有什么

一部普通智能手机，在完全没有网络的情况下，仍然是一台集成了十几种传感器的便携仪器。关键在于：这些功能不依赖联网，只依赖电和预先装好的应用。

一个容易被忽略的事实

手机的 GPS 不需要流量、不需要 SIM 卡。它接收的是卫星单向广播信号。真正的前提是你手里有离线地图，否则你只能得到一串经纬度数字，却不知道该往哪个方向走。

最容易被忽视的耗电陷阱

很多人断网后第一反应是"不停刷新看看有没有信号"。这个动作会在几小时内耗尽一块满电电池，而你什么也没得到。正确的做法是：固定每天开机 2–3 次，每次 10–15 分钟，集中在需要定位、照明或记录的时刻。

1.5 低温电池管理

锂离子电池在 0 °C 以下容量明显下降，−20 °C 时可用容量可能只剩一半左右，而且电压骤降会让你以为"还有 40% 却突然关机"。这不是坏了，是冻的。

  • 贴身存放。内层衣袋、腋下、腹部。体温能让电池恢复到接近常温性能。
  • 不要在有水汽的地方从冷到暖。从 −20 °C 进到暖房，机身内部会结露。正确做法是装进密封袋再回温，等恢复到室温再开机。
  • 0 °C 以下不要充电。低温充电会在负极析出金属锂，永久损伤电池，严重时鼓包起火。必须等电池回到 0 °C 以上再充。
  • 备用电源同样要保温。充电宝放在睡袋里，不要扔在帐篷角落。
  • 关机比待机更抗冻。长时间不用就关机，减少低温下的自放电与电压跌落。

  • 关键数值刻在木片、骨片、金属片上

1.8 数字信息的三个陷阱

  1. "离线可用"是营销词。很多应用宣称离线，实际首次启动、每隔几天、或切换功能时都要联网校验。断网前务必在飞行模式下实测一遍。
  2. 地图缓存有范围。多数离线地图只缓存你当时屏幕附近的区域和缩放级别。以为"下载了整个省"，结果放大到街道级别是空白——这种情况非常常见。
  3. 账号会锁死。需要登录才能看的内容，在无法接收验证码时等于零。把关键资料导出成不需要登录的本地文件。

02优先级：第一小时到第三天

慌乱中的人会做很多事，但通常不是最该做的那件。这一章给你一个不会错的顺序。

2.1 三法则在极寒下的修正

通行的"3-3-3 法则"是：缺氧 3 分钟、无庇护 3 小时、无水 3 天、无食 3 周。它在温带成立，但在极寒里必须修正：

资源温带估算极寒修正原因
庇护约 3 小时30 分钟 – 2 小时风寒、湿衣、强对流让体热流失速度成倍增加；落水后可能只有十几分钟
水约 3 天约 1–2 天冷利尿（寒冷时排尿增多）、呼吸失水、融雪取水耗燃料，实际更容易脱水
食物约 3 周约 1–2 周（有脂肪储备者更久）维持体温需要额外热量，寒冷环境每日消耗可达 3000–5000 kcal
排序不变，但时间窗口压缩

顺序永远是：止血/呼吸 → 脱离危险源 → 保温与庇护 → 信号 → 水 → 食物。极寒只是把"庇护"这一项的截止时间从几小时压到了几十分钟。

2.2 第一小时：只做六件事

  1. 停下来，别走。除非当前位置本身致命（雪崩堆积区、冰面、崖底、车道上），否则先停。继续走只会让你出汗、迷路、消耗判断力。
  2. 清点人与伤。有没有人湿了、抖了、说话含糊、走路不稳？失温的早期信号优先于一切物资问题。
  3. 切断风与湿。找背风面（岩石、树丛、土坡、车辆侧面），穿上所有能穿的干衣，把湿外层脱掉或拧干。坐下时垫东西，不要直接坐雪地。
  4. 决定：蹲守还是移动。距离天黑不足 2 小时、能见度差、有人失温、地形不熟——蹲守。四个条件都良好且你有明确目的地——可以移动，但要留足返程时间。
  5. 发出信号。哨子（三短三长三短）、反光、鲜艳衣物铺在雪地上。声音和颜色在雪地里传播得比你想的远。
  6. 记录。写下时间、位置、人数、物资、决定。之后每 2 小时更新一次。失去时间感是危险的开始。

03保暖与失温处置

这是极寒场景里最高频的死因，也是最容易被"常识"害死的部分。很多流传的做法是错的，而且错得致命。

3.1 热量是怎么丢的

途径影响程度怎么堵
传导（接触冷物）坐雪地、贴岩石时极快永远垫隔热层：树枝、干草、背包、泡沫垫。厚度比材质更重要
对流（风）风寒效应可让体感低 10–20 °C防风层优先于加厚。一件薄风衣挡风，效果可能超过一件厚毛衣
辐射（向环境散热）持续存在减少暴露面积，蜷缩，加反射层（急救毯）
蒸发（汗与呼吸）被严重低估不要出汗。走起来就减衣，停下立刻加衣
纠正一个流传很广的说法

"人体 40% 的热量从头部散失"源自上世纪一项军事实验，受试者穿着厚衣但不戴帽。真实比例取决于暴露面积。结论仍然实用——该戴帽子就戴——但不必以为戴了帽子就万事大吉。脖子、手腕、脚踝这些"缝隙"同样在漏热。

3.2 三层穿衣法与极寒修正

层作用材料优先级常见错误
内层（排汗）把汗从皮肤表面带走美利奴羊毛 > 聚酯纤维 >> 棉穿棉内衣。棉吸水后不干，湿棉贴身等于持续失温
中层（保暖）困住静止空气羽绒 > 抓绒 > 羊毛穿太厚导致出汗，停下来立刻变冷
外层（防风）挡风、挡雪防水透气硬壳只防雨不透气，汗气闷在里面
第四层（极寒）静态保暖厚羽绒/派克大衣穿着它走路，必然大汗

核心原则：多薄层优于一件厚。因为你可以随时增减，而一件厚衣服只有"穿"和"脱"两个状态。

第二个原则：出发时觉得有点冷，是对的。走 10 分钟后身体会热起来。如果出发时刚好舒服，10 分钟后必然出汗。

出汗 = 把保温层变成散热层

湿透的内层导热率是干燥时的数倍，而且离开火源后很难干。一次大汗可能让你在当晚就出现失温。控制节奏、主动减衣、及时停下，比任何高级装备都重要。

3.3 必须保护的部位

  • 手：薄内衬手套 + 厚外手套。需要精细操作时只脱外层，不要把两只手都暴露。
  • 脚：鞋不能太紧，太紧会压迫血管，脚趾最先冻伤。羊毛袜 + 备用干袜。鞋内衬塑料袋（蒸汽屏障）能防汗浸湿鞋垫，但会让脚更潮，只适合极低温短时使用，且每天必须彻底干燥。
  • 头颈：帽子 + 围脖。围脖比围巾好，不会松脱，还能拉起来护住口鼻。
  • 眼：雪面反射紫外线极强，阴天也会晒伤角膜。戴墨镜或用窄缝护目（见 12.6）。
  • 脸：面罩呼出的水汽会结冰，反而冻脸。可以只在迎风时拉起，注意及时抖掉冰碴。

3.4 湿是头号敌人：每日干燥流程

  1. 睡前换干。把袜子、内层、手套全部换干的。湿的塞进睡袋只会让睡袋也湿。
  2. 用体温烘干。把湿袜、湿手套放在腋下、腹部、大腿内侧，睡一夜能半干。这是最可靠的方法。
  3. 抖雪。进庇护所前把身上、鞋上、背包上的雪彻底抖掉。雪进屋化成水，等于往睡袋里倒水。
  4. 翻晒睡袋。睡袋内层会结露。白天（哪怕阴天）摊开抖一抖，让水汽散掉。别在 −30 °C 下暴晒，面料会变脆。
  5. 修补破口。衣服上的小口子会灌风灌雪，用胶带、针线、甚至筋线缝住。

3.5 睡袋与卧具

  • 看"舒适温标"，不看"极限温标"。极限温标是"不至于冻死"的温度，不是"能睡着"的温度。
  • 地面隔热比睡袋更重要。雪地导热极快，需要 R 值 4 以上的垫子，或用 20–30 cm 厚的树枝、干草、蕨类铺底。
  • 脚下加料。脚冷多半是因为脚下没有隔热层。背包、备用衣物、干草塞在脚下。
  • 睡前先热起来。做几十个深蹲或原地踏步，让身体发热再钻进睡袋。但不要出大汗。
  • 睡前排尿。膀胱充盈会让身体持续散热，而且半夜起来更痛苦。
  • 睡前吃点脂肪。身体消化脂肪产热，能帮你熬过后半夜的低温低谷。
  • 不要穿湿衣睡，也不要穿太多层睡。穿太多会压迫血管、影响睡袋蓬松度，反而更冷。

3.6 失温：识别分级

失温是核心体温下降，不是"觉得冷"。判断依据是意识和身体控制能力，不是自我感觉。人在中度失温时反而可能觉得"不冷了"，这是危险的假象。

分级核心温度（参考）表现处置强度
轻度35–32 °C持续寒战、手脚麻木、动作笨拙、言语含糊但意识清醒现场复温，可自行行走
中度32–28 °C寒战减弱或停止、意识模糊、判断力下降、步态不稳、可能反常脱衣必须担架/搀扶，禁止自行行走
重度< 28 °C昏迷、呼吸浅慢、脉搏微弱难测、瞳孔对光反应迟钝L4 致命，轻柔搬运，立即送医
最关键的一条识别原则

寒战停止不是好转，是恶化。轻度失温的人会一直抖；当他不再抖、变得"安静""配合""想睡觉"，说明体温调节已经失效，进入中度以上。此时每一分钟都在走向死亡。

3.7 失温现场处置：八步

  1. 脱离暴露。移到背风处，切断风、雪、湿地面。动作要轻，不要让患者自己走（中度以上）。
  2. 脱掉湿衣。用剪刀剪开比脱更快，也减少搬动。湿衣会持续带走热量，必须去掉。
  3. 隔地、隔热、隔风。先铺隔热层，再裹保温层，最外层防风。急救毯（反射层）贴身在保温层内侧效果最好，不要直接贴皮肤。
  4. 核心区加温。热量优先给颈部、腋下、腹股沟、胸部——那里是大血管经过的地方。用热水袋（必须用布包好，防止烫伤无感觉的皮肤）、暖宝宝、同伴体温。
  5. 意识清醒且能吞咽：给温热糖水。小口、多次。糖能提供产热底物，温热液体能补充热量和水分。
  6. 禁止四件事：搓手脚、喝酒、剧烈运动、直接烤火。原因见 3.9。
  7. 重度患者：水平搬运，避免颠簸。冷的心脏对震动极其敏感，粗暴搬动可能诱发心室颤动。用担架、睡垫拖行，不要背、不要扛。
  8. 缓慢复温，持续监测。复温速度大约每小时 0.5–1 °C。不要用热水浴、不要用高温热源，外周血管突然扩张会让冷血回流心脏，导致核心温度进一步下降（复温休克）。

3.8 冻伤：识别与复温

冻伤是局部组织结冰，和失温是两件事。常见部位：手指、脚趾、鼻尖、耳廓、脸颊。

程度表现预后
一度（冻伤前兆/冻疮）皮肤苍白、麻木、僵硬，复温后红肿、刺痛可完全恢复
二度（浅层冻伤）复温后出现清亮水泡，周围红肿多数可恢复，可能留疤
三度（深层冻伤）皮肤蜡样、发紫发黑、血性水泡、复温后无痛感（神经已损）可能坏死截肢，必须送医

正确复温

  1. 先判断：还能不能不复温就走出去？如果脚冻伤且必须靠双脚撤离，宁可冻着走。复温后的组织极度脆弱，再冻结的损伤远大于持续冻结（"走着出去，别躺着冻着"原则）。
  2. 移到温暖环境。脱掉湿衣、摘掉戒指手表（肿胀后会卡死）。
  3. 温水浸泡：37–39 °C。用手肘试温，感觉"温热不烫"。超过 40 °C 会烫伤无感觉的皮肤。
  4. 浸泡 20–30 分钟，直到皮肤变软、颜色转红。复温过程会很疼，这是好现象，说明神经还活着。
  5. 轻轻拍干，不要擦。趾间用干布分开，垫上干的纱布或棉花，避免摩擦。
  6. 水泡不要刺破。水泡是天然敷料，破了会感染。
  7. 复温后绝对不能再冻。保持温暖，抬高患肢，尽快转运。
冻伤禁止清单（每一条都会加重损伤）
  • 不要用雪搓。冰晶会像砂纸一样破坏已经受损的组织。
  • 不要摩擦按摩。同上，机械损伤 + 疼痛。
  • 不要用火烤、电吹风、热水袋直接贴。组织麻木，感觉不到烫，会烧穿。
  • 不要喝酒"暖身"。酒精扩张外周血管，加速核心热量散失，同时削弱判断力。
  • 不要挑破水泡。感染风险极高，且没有抗生素。

3.9 雪盲

紫外线经雪面反射灼伤角膜，潜伏期 4–12 小时。症状：眼内有沙砾感、畏光、流泪、剧痛、睁不开眼。

  • 预防：任何雪地活动都戴护目。阴天同样需要——云层不挡紫外线。
  • 处置：避光、闭眼休息、冷敷。通常 24–48 小时自行缓解。
  • 不要揉眼。会加重角膜损伤。
  • 临时护目：硬纸板、树皮、布条开一条 2–3 mm 窄缝，只留水平视野。简陋但有效。

04庇护所：把死亡挡在门外

在极寒里，庇护所不是"睡觉的地方"，是"让你活到明天的基础设施"。它排在食物之前，通常也排在找水之前。

4.1 选址六条

  1. 背风。找岩石、土坡、密林的背风面。风是最大的热量窃贼，挡住风等于升高 10 °C。
  2. 避开死亡地形。陡坡下方（雪崩堆积区）、冰面、孤立枯树下（雪压断枝）、河床（夜间水位/冰裂）、崖底（落石）。
  3. 靠近资源但不贴水。离水源 50–100 m 方便取水，但不要扎在河岸或冰面上——夜间温度骤降、冰层变化。
  4. 地面平整、可排水。雪地要找压实的地方；如果必须挖，留出排水沟，避免化雪把睡袋泡了。
  5. 可被发现。不要藏进深沟。在能看见天空、能被空中搜救发现的位置，同时留出开阔地发信号。
  6. 有柴。枯立木、倒木、干枝。距离超过 100 m 会让每晚的燃料收集变成苦役。

4.3 雪洞：详细施工

雪洞是极寒环境里性价比最高的庇护所。原理很简单：雪是多孔材料，含大量静止空气，是极好的隔热层。外面 −30 °C 时，洞里可以维持在 0 °C 附近。

  1. 选址。找积雪山坡，坡度 20–30°，雪层厚实且稳定。避开雪檐（wind slab）、裂缝、树根。用登山杖或树枝试探雪深，至少 1 m，理想 1.5–2 m。
  2. 画门。在坡面上画一个直径约 1 m 的圆，作为入口。
  3. 向内挖。用铲子、雪鞋、锅、木板，向斜上方挖进。挖出的雪堆在洞口两侧作为挡风墙，不要扔远。
  4. 先小后大。入口通道窄（刚好能爬进），进到里面再扩大成一个能坐起、能躺下的空间。这样省力，结构也更稳。
  5. 做睡眠平台。把内部地面挖成一个高出入口 20–30 cm 的平台。冷空气密度大会沉到入口低处，平台上是暖区。这一步是雪洞保温的关键。
  6. 修圆顶。顶部做成拱形，不要平顶（平顶易塌）。洞顶厚度至少 30 cm，可用树枝从外面捅进来做厚度标尺。
  7. 开通风孔。用登山杖或长枝从顶部斜向上捅穿一个直径 5 cm 以上的孔。必须有两个（进气+出气）或至少一个足够大的孔。睡前检查一次，醒来检查一次——夜里结霜可能堵死。
  8. 门口处理。用背包、雪块挡一下入口，但不要封死。留出能快速爬出的通道。
  9. 铺床。平台上铺树枝、干草、泡沫垫、背包。厚度 10 cm 以上。
雪洞的三条生死线
  • 通风孔必须畅通。雪洞密闭性很好，人体呼出的二氧化碳、以及任何明火产生的一氧化碳都会积聚。头痛、恶心、昏昏欲睡 → 立即钻出去。
  • 不要在雪洞里用炭火、燃气炉。这是经典的一氧化碳死亡场景。
  • 顶部厚度不足会塌。30 cm 是下限，暴雪后要重新检查。听到"咯吱"的沉降声，立刻离开。

如果只有蜡烛：一根蜡烛能让小雪洞温度上升几度，也能消耗部分氧气、产生一点一氧化碳——只有在通风良好的情况下才允许，并且睡前必须熄灭。

4.4 雪壕与雪堆屋

雪壕（snow trench）

  1. 挖一条长 2 m、宽 0.6–0.7 m、深 0.8–1 m 的沟。
  2. 沟底铺树枝隔热，做成睡台。
  3. 顶部横铺树枝、滑雪板、背包，再盖 20–30 cm 雪块。
  4. 一端留出口并开通风孔。入口用背包挡风，不要封死。

雪堆屋（quinzhee）

  1. 堆一个直径 2–2.5 m、高 1.5 m 的雪堆，边堆边拍实。
  2. 插一圈 30 cm 长的树枝作为厚度标尺，均匀分布在雪堆表面。
  3. 静置 1–2 小时让它烧结定型（时间允许的话）。
  4. 从侧面挖入口，向内部掏空，挖到露出树枝末端就停——那就是 30 cm 厚度。
  5. 内部同样做高台、开通风孔。

4.5 披屋与树林庇护

没有深雪但有树，就用披屋。核心是脊木 + 斜面的密集覆盖层。

  1. 找一根横木（脊木），一端架在树杈或石头上，离地约 1 m；另一端落地。
  2. 沿脊木斜铺短枝，形成 45° 斜面。
  3. 铺针叶、枯枝、树皮、苔藓，厚度至少 30–45 cm。薄了会漏雪、漏风、漏水。
  4. 开口背风。地面铺 20 cm 以上枝叶做床。
  5. 在开口前方 1–1.5 m 处生火，并搭一道反射墙（木堆、雪块、岩石），把热量反射回棚内。
  6. 屋顶预留透气缝隙，不要在密闭棚内烧火。
为什么铺垫要那么厚

人体压下去会把枝叶压实一半。铺 20 cm，躺上去只剩 10 cm，隔热远远不够。看起来"过分厚"的铺垫，才是刚好的。判断标准：躺下后感觉不到地面的冷。

4.6 远古环境：洞穴与兽皮帐

远古场景没有雪洞工具，也没有合成材料，但原理完全相同：挡风、隔热、隔湿、通风。

洞穴改造

  • 先查住户。洞口有爪印、粪便、毛发、骨头残渣 → 可能有熊或其他动物。不要贸然深入。
  • 查落石。顶部有裂缝、渗水、新鲜碎石 → 不稳定。
  • 挡风。用树枝编篱、兽皮、雪块封住部分洞口，留出人能进出的开口。
  • 抬高睡台。地面冷且潮。用石头、木头、干草搭一个离地 20–30 cm 的平台。
  • 分区。火塘靠洞口（排烟方便），睡眠区在深处，储物区在中间。火塘周围用石头围一圈。
  • 排烟。洞口上方要有缝隙形成对流。烟倒灌说明通风不足，宁可开大一点。

兽皮帐篷

  • 骨架：几根长木杆交叉绑扎，形成圆锥形。底部直径 3–4 m。
  • 覆盖：兽皮缝合成大片，毛面朝内（保暖），或毛面朝外（防雪）。实际以毛朝内更保暖。
  • 底部压石头或雪块，防止灌风。
  • 顶部留排烟口，可调节开合。
  • 地面铺干草、兽皮。睡眠区与火塘分开。

4.7 营地布局

一氧化碳无色无味，早期症状是头痛、头晕、恶心、乏力——和疲劳、高原反应很像，极易误判。接着会出现"觉得很困，想睡一觉"，然后就不再醒来。任何在封闭或半封闭空间用火的行为，都必须保证有持续对流；睡前必须熄灭所有明火。

05取水：最容易被低估的难题

周围全是雪，你却可能在第三天脱水倒下。极寒环境的取水难点不在"找",而在"化"和"带"。

5.1 为什么寒冷环境更容易脱水

  • 冷利尿：寒冷时外周血管收缩，血液回流核心，肾脏灌注增加，排尿增多。
  • 呼吸失水：每呼出一口气都带着水汽，在 −20 °C 下每天经呼吸丢失的水分相当可观。
  • 口渴感迟钝：低温下口渴中枢反应变弱，你不会像夏天那样主动想喝水。
  • 取水成本高：化雪要燃料、要时间，人会不自觉地"省着喝"，这是危险的自我节流。
  • 误判：以为吃雪就是补水。吃雪会降低核心温度、刺激口腔黏膜，实际得不偿失。

5.2 水源优先级

优先级水源处理成本说明
1流动的活水（溪流、涌泉）低（仍需煮沸/过滤）细菌负荷相对低，取水快
2冰块（尤其是发蓝、致密的湖冰）中比雪省燃料得多，1 L 冰约出 0.8–0.9 L 水
3压实雪 / 湿雪中高约 5:1 到 8:1（体积比）
4松散干雪极高约 10:1，最不划算，只作应急
5雨水、融霜低相对洁净，但仍建议煮沸
6植物蒸腾水（塑料袋套树枝）低但产量小针叶树可收集少量，杯水车薪

5.3 融雪融冰：三个关键技巧

  1. 锅底先放一点水。空锅直接加雪，雪会先把热量吸走，锅底局部过热干烧，容易烧穿、变形、甚至开裂。先倒 1–2 cm 水，再一点点加雪。
  2. 少量多次，不要一次塞满。雪放进锅里会迅速融化塌陷，一次加太多反而更慢。保持"半锅雪水混合物"的状态效率最高。
  3. 优先用冰，其次用湿雪。同样一锅水，冰的燃料消耗可能只有松散雪的三分之一。看到结冰的水坑、冰柱、河冰，优先取冰。
燃料账：这才是真正的约束

用一小锅（约 1 L）融化松散雪取水，在 −15 °C 环境下可能需要 15–25 分钟的持续大火。一天要喝 2–3 L，意味着你可能要烧掉几公斤柴。这就是为什么"靠近水源"和"有柴"要同时纳入营地选址。

不要吃雪解渴

吃雪会消耗核心热量去融化它，同时刺激口腔和胃，越吃越冷。紧急情况下可以含一小块冰慢慢化，但不等于补水。真正补水只能靠融化成液体后再喝。

5.4 净化：没有净水器怎么办

野外水源可能含有细菌、原虫（贾第虫、隐孢子虫）、病毒和寄生虫。极寒不能杀菌——很多病原体在冰里能存活很久。

方法有效性操作要点局限
煮沸最可靠，杀灭所有病原体滚沸 1 分钟；海拔 2000 m 以上滚沸 3 分钟耗燃料；不能去除化学污染
滤水器（0.2 μm）除细菌、原虫按说明书，注意防冻（滤芯结冰会失效）不除病毒；浑浊水要先沉淀
二氧化氯片广谱，含病毒浑浊冷水需 4 小时以上有味；需等待；低温下反应更慢
碘片 / 碘酒细菌、病毒、部分原虫按比例，静置 30 分钟以上孕妇、甲亢患者禁用；不杀隐孢子虫

太阳能消毒（SODIS）部分细菌透明瓶装满，强光下晒 6 小时以上冬天几乎无效；阴天不可靠

组合策略最稳：布滤去悬浮物 → 静置沉淀 → 煮沸。如果燃料紧张，过滤 + 化学消毒也可以，但化学法在冰水里要延长等待时间（按 2 倍算）。

5.6 其他收集方式

  • 冰柱：屋檐、岩壁下的冰柱，相对洁净，融化效率高。
  • 雪坑集水：在向阳处挖坑，铺深色布/石头吸热，白天可收集少量融水。
  • 树干取水：桦树在早春可钻孔取汁（每天每树几百毫升），但会伤树，且不是所有季节都有。
  • 冷凝水：在火上方的布上凝结水汽，效率很低，只适合极端情况。
  • 雨水：用布、防水布、大叶子收集。相对洁净，但仍建议煮沸。

5.7 储水与防冻

  • 不要装满。水结冰体积膨胀约 9%，装满的容器会裂。留 1/4 空间。
  • 睡前放睡袋。把水壶放在睡袋里，用体温防冻。第二天起来就有液态水。
  • 埋进雪里。雪是隔热层，埋在 30 cm 深处比放在空气中更不容易冻实。
  • 倒置悬挂。瓶口朝下挂，结冰从表面开始，瓶口反而不易冻死。
  • 金属容器不要贴皮肤。 −20 °C 的金属会瞬间粘住皮肤，撕开就是伤口。

情况最低量建议量

轻度活动2 L2.5–3 L

判断补水是否足够最简单的方法：看尿液颜色。淡黄接近透明 = 正常；深黄 = 需要补水；茶色 = 严重脱水，必须立即处理。

06生火：从一点火星到一夜温暖

火在极寒里同时是取暖、净水、烹饪、信号、照明和心理支柱。它值得你花一整个下午去准备。

6.1 三要素，以及极寒给你的三个难题

燃烧需要燃料、氧气、热量。道理都懂，难的是在 −20 °C 的雪地里同时凑齐这三样：

6.4 极寒生火：八步流程

  1. 先搭平台。用两根粗湿木并排，或几块石头，铺成一个离雪面 10–15 cm 的底座。火直接在雪上会融化下陷并熄灭。
  2. 清出火场。直径 1 m 内清掉积雪，露出地面或压实雪。周围不要有低垂树枝。
  3. 备足燃料再点火。按"引火物 → 细柴 → 中柴 → 粗柴"分四堆摆好，一臂之内可取。点着之后再去找柴，是最常见的失败原因。
  4. 搭火巢。引火物做成鸟巢状，中间留空隙；上面架细柴成锥形或井字形，留出进气通道。
  5. 背风点火。蹲下用身体挡风，从迎风面点火，让火焰往燃料堆里烧。
  6. 先小后大。火苗稳定后再加细柴，逐步加粗。不要一开始就压大木头。
  7. 保持进气。火要"呼吸"。柴堆太密会闷，留缝隙；风太大就用石头/雪块挡一侧。
  8. 建立火种。火稳定后，把几根粗木并排放入，让它慢慢烧成炭。这些炭是下一堆火的种子。

6.5 湿柴怎么烧

  • 劈开取芯。湿木只有外层吸水，内部是干的。劈成四瓣，用内芯做细柴。
  • 做"羽毛棒"。在木棒一端反复削出薄片但不削断，形成羽毛状。增加表面积，极易点燃。
  • 用火烤干。把湿柴斜靠在火堆旁 30–50 cm 处烘烤，不要直接扔进火里（会大量冒烟、降温）。
  • 找枯立木。站着的死树，尤其是树皮脱落、敲击声脆的，内部通常干燥。
  • 松脂助燃。针叶树的树脂节、桦树皮含油脂，是天然的助燃剂。

6.7 燃料管理

  • 一夜的量要提前备。持续火整夜约需 15–25 kg 硬木；星形火可减半。不要半夜起来摸黑找柴。
  • 干湿分开堆。干柴放庇护所内或盖雪布下；湿柴放火边烘。
  • 粗细分堆。夜间加柴用粗木，慢燃；早起引火用细柴，快燃。
  • 碳比火更值钱。睡前把粗木烧成炭，用灰埋住，第二天早上扒开还能复燃。
  • 别烧雪压木。被雪压过的倒木含水率高，烟大热量低。

6.8 火的用途与安全边界

火的六种用途

  • 取暖、烘干衣物
  • 煮沸净水、烹饪
  • 信号（三堆火、烟柱）
  • 照明、驱赶动物
  • 加工工具（火烤硬化木矛、软化木条）
  • 心理支撑（不要低估）

五条安全边界

  • 帐篷内不用炭火、燃气炉
  • 睡前熄灭所有明火
  • 火堆 2 m 内清雪、清枯枝
  • 备好雪/水用于扑救
  • 离开前彻底浇灭、翻灰
雪地灭火不等于用雪盖

雪盖在火上会融化、变成水，再被下面的热量蒸干，容易在几小时后复燃。正确做法是浇水 → 搅拌 → 再浇水 → 手背靠近感觉不到热。如果只有雪，就用大量雪反复覆盖并翻动，直到完全冷却。

07觅食：热量账与风险账

极寒环境里，找食物的投入产出比通常很差。先算清账，再决定要不要为一只兔子走三公里。

7.1 先算热量账

寒冷环境每天可能需要 3000–5000 kcal。而一只野兔大约只有 1000–1500 kcal，且大部分是极瘦的蛋白质。这意味着：靠打猎维持热量，在体力上几乎不可能。食物的真正价值在于补充脂肪、维持士气、提供微量营养。

营养素热量在极寒中的角色
脂肪约 9 kcal/g核心。产热效率最高，也是脂溶性维生素的来源
蛋白质约 4 kcal/g维持肌肉，但过量蛋白质代谢需要大量水，加重脱水
碳水约 4 kcal/g快速供能，适合活动前和急救时
"兔饥饿症"（rabbit starvation）

只吃极瘦的兔肉、鱼肉，即使吃到饱，也可能出现恶心、腹泻、头痛、极度疲劳。原因是蛋白质过高、脂肪过低，肝脏无法处理如此多的蛋白质。解决办法不是多吃肉，而是补充脂肪：动物脂肪、骨髓、鱼油、坚果、蛋黄。没有脂肪来源时，宁可减少活动量、降低消耗。

7.2 觅食优先级

顺序来源风险说明
1自己携带的储备粮无优先消耗，不要"舍不得吃"
2人类建筑内的遗留食物低（检查变质）罐头、密封包装优先
3鱼（冰钓、溪流）中（寄生虫）产量相对稳定，但脂肪低

5昆虫低–中（过敏）高蛋白高脂，冬季难找
6植物（针叶、树皮、根茎）中（误认）热量低，主要提供维生素和纤维
7大型动物高（危险、处理量大）一头鹿可提供大量肉和脂肪，但需要团队和工具

7.3 冰钓

冰钓是极寒环境里最稳定的蛋白质来源之一，前提是冰够厚。

  1. 判断冰厚。经验值：静水（湖、塘）10–15 cm 可承单人；流动水域需要更厚且不均匀，风险高得多。冰色发蓝、致密 = 结实；发白、蜂窝状 = 不稳；岸边有裂缝、水渗出 = 不要上。
  2. 结伴、系绳。两人以上，腰间系绳连到岸边，带冰锥（或长木棍）和哨子。
  3. 开洞。用冰钻、斧头、撬棍。洞口直径 15–20 cm。开洞后立刻把碎冰捞走，否则很快复冻。
  4. 钓具。线（鱼线、尼龙绳拆股）、钩（骨钩、别针、铁丝弯制）、饵（昆虫、小块鱼肉、红色布条）。
  5. 钓法。钩饵沉到接近底部，缓慢上下提动，模拟挣扎。每 5–10 分钟换位置。
  6. 保温。坐着钓比站着更省体力，但必须垫隔热层，脚不能贴冰。每 20 分钟活动一次脚趾。
  7. 收工。把洞口用雪封住，标记位置，避免自己或他人踩空。
不确定就不要上冰

冰面判断没有 100% 可靠的方法，尤其是积雪覆盖的冰、有暗流的河冰、春季融冰。落水的存活时间以分钟计（见 14.4）。如果必须冒险，只走别人已经走过的路线，解开背包肩带，带一根长杆横在身前。

7.4 套索与陷阱

陷阱的优势是"设好就走"，不消耗持续体力。缺点是命中率低，需要布设多处。

  • 兔套：用细铁丝（20–24 号）做一个直径 10–12 cm 的活套，离地 10–15 cm，布在兔子常走的"兔道"上（雪地里被踩出的小径、粪便附近）。另一端固定牢固。
  • 鸟套：多个小活套布在鸟常停歇的枝头，或用套索围住诱饵。
  • 落石陷阱：用重石 + 支棍 + 触发线，目标是小动物。威力大，必须标记位置，防止同伴误触。
  • 鱼梁：在浅溪用石头垒成 V 形，把鱼导向窄口，放鱼篓或直接手抓。

布设原则：沿动物足迹、粪便、啃食痕迹布置；入口要自然，不要留下人的气味（可用雪搓手、烟熏）；每天检查一次，避免猎物腐败或被其他动物吃掉；所有陷阱必须做醒目标记。

7.5 处理猎物

  1. 确认死亡、确认物种。不确定的动物不要吃。检查是否有明显病变（脓肿、异常消瘦、毛发脱落）。
  2. 放血。切开颈部血管，让血流出。放血能延缓腐败、改善风味。
  3. 去内脏。从胸骨到肛门切开，取出内脏。保留心、肝、肾（营养密度最高），丢弃肠道内容物。
  4. 冷却。把胴体挂在通风阴凉处，或埋进雪里快速降温。极寒是天然冰箱，但要注意别冻成石头（影响分割）。
  5. 剥皮。从腿部开口，整张剥离。皮可以做成衣物、绳子、容器（见 8.5）。
  6. 分割。按关节分割，不要砍骨头（浪费骨髓，也容易崩刀）。
  7. 彻底煮熟。所有野生肉都必须全熟，内部温度达到 60 °C 以上，肉色完全变褐、汁液清澈。
三种必须记住的禁忌
  • 不要吃北极熊肝脏。维生素 A 含量极高，可致急性中毒（头痛、呕吐、脱皮，严重时死亡）。
  • 熊肉、野猪肉必须彻底煮熟。旋毛虫感染风险，冷冻不一定能杀死（部分虫株耐冻）。
  • 不要吃不明原因的死亡动物。病死动物可能携带炭疽、狂犬病、禽流感等。宁可饿，不要赌。

7.6 可食用植物（极寒与针叶林）

植物在冬季提供的热量很有限，但能提供维生素 C、纤维和口感变化。以下都是相对容易确认的种类，但仍要求 100% 确认后再入口。

7.7 绝对不碰

  • 任何白色、带菌环、菌托的蘑菇（鹅膏属风险）。
  • 任何有乳汁、有苦杏仁味、蓝色/紫色小浆果的不明植物。
  • 豆科不明植物的种子（部分含剧毒生物碱）。
  • 发霉的谷物、坚果（黄曲霉毒素，耐高温，煮不死）。
  • 发芽的土豆、青西红柿（龙葵素）。
  • 不认识的海藻、贝类（麻痹性贝毒，煮不死）。

7.8 烹饪与寄生虫

  • 所有野生肉、淡水鱼必须全熟。不要吃生鱼片，不要"五分熟"。
  • 煮比烤可靠。烤容易外焦里生，煮能保证中心温度。
  • 内脏要彻底清洗并煮透。肝脏可以吃，但必须熟。
  • 生熟分开。切生肉的刀和板，用开水烫过再处理熟食。
  • 不要喝生水配生肉。双重感染风险。

08远古环境：从零开始造一套工具

没有金属、没有绳索、没有容器。你要用石头、骨头、木头和筋腱，重建人类花了几十万年才攒出来的那套东西。

8.1 先认清优先级

不要一上来就打制精美的石斧。按"能立刻改善生存"的顺序：

顺序工具为什么先做
1锋利的石片（不需要装柄）能切割、刮削、处理猎物，几分钟就能做出来
2取火工具（弓钻组）火是一切的基础
3容器（桦皮、木槽、皮袋）没有容器就无法储水、煮食
4绳索（筋腱、树皮纤维）绑扎、陷阱、庇护所、武器
5骨针 + 筋线能缝制衣物和帐篷，直接决定能否过冬
6矛 / 弓狩猎，但需要前五项支撑
7陶器长期储存与煮食，但制作周期长

8.2 石料选择与打制

什么石头能用

石料特性获取
燧石（flint）最理想，贝壳状断口，边缘极锋利白垩地层、河床结核，外表灰白、敲开黑色
黑曜石（obsidian）锋利度超过手术刀，但脆火山地区
石英岩 / 石英硬度高，可用，但难控制河床卵石
玄武岩 / 安山岩适合做锤、砍砸器，不适合精细石片山地常见
页岩 / 板岩可磨制成刀、箭头，但脆层状岩石

现场测试：敲击时声音清脆、断口呈贝壳状、边缘能割断草绳 = 好石料。声音沉闷、呈颗粒状断裂 = 不适合。

打制三步

  1. 选台面。找石核上小于 90° 的边缘作为打击台面，这样剥下的石片才可控。
  2. 硬锤粗打。用圆形河卵石（比拳头小一点）快速敲击台面边缘，剥下大石片。目标是得到可用的石片，不是做出漂亮的形状。
  3. 软锤精修。用鹿角、硬木、骨棒轻压边缘，修出锯齿或尖头。没有软锤时，用硬木棍顶端抵住边缘，用手掌推压（压制法）。
安全第一

打制时会产生极锋利的碎屑，戴护目（哪怕是一块布），并在大腿上垫厚皮/布。石片边缘比刀还利，划伤后极易感染。打制产生的废片不要乱扔，集中埋掉或堆在远离活动区的地方。

8.3 骨、角、牙：被低估的材料

  • 骨针：取一段细骨（鸟骨、兔骨），在砂石上磨细，用燧石钻头钻出针眼。这是决定能否做出合身衣物的关键工具。
  • 骨锥：磨尖的骨片，用于在皮革上穿孔。
  • 骨钩：弯钩状骨片，磨出倒刺，做鱼钩。
  • 鹿角：硬度适中、有韧性，是做软锤、楔子、矛头的优质材料。
  • 牙齿：可做刮削器、钻孔器、装饰品。

加工方法：先用石片刮出粗形，再在湿砂石上研磨。骨头不要用火直接烧（会变脆），可以先用热水软化再弯曲。

8.4 纤维与绳索

绳子是人类最早的"复合技术"。没有绳子，你无法绑矛头、搭帐篷、做陷阱、拉雪橇。

材料来源特点
树皮内层椴树、柳树、榆树纤维长、柔韧，最常用
荨麻纤维秋季枯死的荨麻茎强度高，需沤制、剥皮
动物筋腱背部、腿部的长筋干后极硬、湿时柔软，适合绑矛头和缝线
生皮条未鞣制的兽皮切条干后收缩，绑扎极牢，但怕水
云杉根浅层根系柔软耐用，适合编篮、绑扎

反向搓绳法

  1. 取一束纤维，分成两股。
  2. 两股分别向同一方向（如顺时针）捻紧。
  3. 再把两股向相反方向（逆时针）绞合在一起。
  4. 每次绞合后，从两端补充新纤维，保持粗细均匀。
  5. 成品越搓越紧，不会散开。这是所有绳索的基本原理。

8.5 皮革处理

生皮干燥后会变成硬板，必须经过处理才能做衣物。完整流程：

  1. 刮肉。皮剥下后，用骨刮器或石片刮掉内侧的肉和脂肪。越快越好，否则腐败。
  2. 刮脂（去脂）。把皮绷在框架上，反复刮薄，直到均匀。
  3. 鞣制。没有单宁时，用脑浆鞣制（动物脑组织 + 水，涂抹揉搓）或烟熏。单宁可从橡树皮、栗树皮煮水获得。
  4. 软化。鞣制过程中反复揉搓、拉伸，直到皮革变软。这是最耗体力的一步。
  5. 烟熏。悬挂在冷烟中数小时，烟中的醛类能防水、防腐、固色。
  6. 缝制。用骨针 + 筋线，缝线要留出余量（皮革会收缩）。

没有鞣制条件时，生皮也能用：趁湿裁剪、缝合，干后变硬成形，适合做鞋底、容器、盾牌，但不适合贴身穿。

8.6 容器：没有锅怎么煮

这是远古生存最容易被卡住的一环。没有金属锅，有四种解法：

方法做法优点局限

石煮法的爆裂风险

绝对不要用从河里、溪里直接捡的湿石头。内部含水，加热时蒸汽膨胀会炸裂，碎片和蒸汽会造成严重烫伤。必须选干燥的、致密的火成岩（玄武岩、花岗岩），避开层状、多孔、有裂纹的石头。加热时先放在火边烘干 10 分钟，再放入火中。

8.7 陶器

  1. 选土。找黏性好的黏土，去掉石子、草根。加少量细砂（约 10–20%）减少收缩开裂。
  2. 和泥。加水揉到"不粘手、可塑形"，像硬面团。静置几小时让水分均匀。
  3. 盘筑成型。搓成长条，一圈圈盘上去，每圈压紧、抹平内外壁。壁厚 0.8–1.2 cm，太厚会裂。
  4. 阴干。放在阴凉通风处慢干 3–7 天，避免阳光直射。干透的标志是颜色变浅、重量变轻、敲击声脆。
  5. 预热。烧制前先在小火边烘 1–2 小时，彻底去除残余水分。
  6. 堆烧。把陶器倒扣在柴堆上，周围围上柴，从下方点火，逐渐加大。露天堆烧可达 800–900 °C，足够烧成低温陶。
  7. 缓慢冷却。烧完后不要立刻取出，让灰烬自然冷却几小时，急冷会炸裂。

8.8 武器与狩猎

  • 火烤硬化的木矛：把硬木尖端在炭火中缓慢加热（不要烧焦），反复刮削 + 加热，尖端会变硬。适合刺击。
  • 装柄石矛：石片嵌入劈开的木杆顶端，用筋线绑紧，再涂松脂胶（松脂 + 木炭粉 + 蜂蜡）密封。
  • 投矛器（atlatl）：一根带钩的短木棒，能把矛投得更远、更有力。原理是延长力臂。
  • 弓：选有弹性的直木（紫杉、榆、白蜡），长度约等于使用者身高。弦用筋腱或搓绳。制作周期以周计，不是应急工具。
  • 围猎：远古人类的主力不是武器，是协作和地形。把猎物驱赶向悬崖、沼泽、雪坑、窄谷，比正面搏斗有效得多。

8.9 弓钻取火（详细）

这是最可靠的原始取火法。四个部件：

部件材料要点
火板干燥软木（雪松、杨、柳、椴）厚 1–1.5 cm，边缘挖一个 V 形缺口，缺口旁钻一个小凹坑
钻杆硬木（榛、桦），长 20–30 cm，直下端磨圆，上端削尖
弓有弹性的弯枝，长 60–80 cm弦用搓绳，留一点松弛
轴承（手压板）石头、硬木、骨压住钻杆顶部，减少摩擦，手掌不烫
  1. 把火板放在地上，脚踩住两端固定。V 形缺口下方垫一片树皮或干叶接火绒。
  2. 钻杆下端放入凹坑，弓弦绕钻杆一圈。
  3. 一手持轴承压住钻杆顶部，一手拉弓，前后匀速运动。
  4. 先慢后快，保持稳定压力。钻杆要垂直，不要晃。
  5. 看到缺口处冒出黑色粉末并开始冒烟时，加快速度、加大压力。
  6. 烟持续稳定后，停止转动，轻轻取出钻杆。缺口里的黑粉中应该有一个发红的火星。
  7. 把火绒轻轻覆在火星上，吹气（不要吹灭），直到起火苗。
  8. 放入准备好的引火巢，逐步加细柴。

失败最常见的原因：木头不干、钻杆打滑、压力不足、转速不够、火绒太粗。每一样都要单独排查，不要同时改所有变量。

8.10 冰河期生存策略

如果环境是真正的冰河期（大型动物、开阔苔原、极低温），单打独斗几乎不可能长期存活。人类靠的是群体、衣物、储藏和迁徙。

  • 跟随兽群。驯鹿、野马、野牛的迁徙路线就是食物路线。沿着河谷和兽道走。
  • 群体协作。围猎、分割大型猎物、守夜、育儿，都需要人手。三人以下的小群体在冰河期极其脆弱。
  • 极致利用。一头大型猎物要全部用掉：肉（食物）、脂肪（热量、灯油）、皮（衣物、帐篷）、筋（线）、骨（工具）、角（武器）、胃（容器）、肠（防水袋）。
  • 储藏。冻土坑、石窖、悬挂风干。冰河期的天然冷冻是最大优势，要善用。
  • 衣物优先于住所。能穿在身上的保暖，比固定住所更灵活。多层兽皮、毛朝内、外层防风。
  • 迁徙而非死守。资源耗尽就移动。固定营地只在有稳定水源、燃料和储藏条件时才成立。

09食物保存：把今天的收获变成下个月的底气

极寒给你一个天然大冰箱，但它不是万能的。反复冻融、动物偷食、脂肪氧化，都会让你的储备归零。

9.1 先理解腐败

食物变质由四件事驱动：微生物、酶、氧化、水分。保存手段的本质，就是至少切断其中一条。

手段切断什么效果
冷冻微生物繁殖、酶活性抑制而非杀死；解冻后腐败速度恢复
干燥水分（微生物需要水）最可靠，重量轻，适合携带
盐腌水分（渗透压）有效，但需要大量盐
烟熏表面微生物 + 氧化配合盐腌效果最好
煮熟密封微生物短期有效，开封后迅速变质
油脂封存氧气适合肉酱、炖肉，需冷藏

9.2 冻结保存

  • 温度要稳定在 −18 °C 以下。雪地表面温度波动大，要埋在背阴、1 m 深的雪坑里，或挖雪窖。
  • 避免反复冻融。这是最伤品质的。白天化、晚上冻，细胞破裂、汁液流失，细菌也会趁机繁殖。
  • 分装小块。一次取一顿的量，不要反复解冻整块。
  • 防动物。埋深、压重石、远离营地但也别太远（方便取用与看守）。
  • 标记日期。用刻痕、布条、木牌标记。雪埋的东西很容易忘。
天然冷冻的保质期不是无限的

脂肪在 −18 °C 下仍会缓慢氧化，出现"哈喇味"。瘦肉可存数月，肥肉建议 2–3 个月内用完，或炼成油密封保存。

9.3 风干与冻干

  1. 切薄。肉切成 0.5 cm 左右的薄片，顺纹切。越薄越快干。
  2. 轻腌（可选）。用盐水浸泡 30 分钟，或抹薄盐，能抑制表面细菌、加速脱水。
  3. 悬挂。挂在通风、向阳、离地 1.5 m 以上的架上。用布条或细枝隔开，避免粘连。
  4. 条件。气温 −5 °C 以下、空气干燥、有风。白天晒、夜间冻，反复循环效果最好（冻干）。
  5. 时间。薄片 2–5 天。判断标准：掰断时"啪"一声脆响，断面没有潮湿感。
  6. 防动物与鸟。用布罩住，或挂在营地视线范围内。
  7. 储存。装进布袋、皮袋，避光、防潮。可保存数月。

9.4 烟熏

类型温度时间效果前提
热熏60–80 °C2–6 小时熟制 + 风味，短期保存（数天到两周）可直接吃
冷熏< 30 °C1–3 天长期保存（数月）必须先盐腌，否则不安全

烟熏装置：挖一个浅坑做火塘，旁边用石头垒一个烟道，上方架肉。用湿木、松针、苔藓产生浓烟。火要小，只冒烟不起明火。肉与火的距离要保证不会烤熟（冷熏）或被直接烧焦。

烟熏不是万能的

烟熏主要作用于表面，内部仍可能腐败。冷熏前必须盐腌脱水，否则肉会在熏制过程中烂掉。没有把握时，宁可把肉煮熟吃掉，也不要赌一个半成品储备。

9.5 盐与替代方案

  • 海水煮盐：1 L 海水约含 30–35 g 盐。煮沸蒸发，剩下湿盐，再炒干。缺点：极耗燃料，1 L 海水需要长时间沸腾。
  • 岩盐：内陆盐矿、盐碱地表面结壳，可刮取后溶解、过滤、再结晶。
  • 替代：烟熏 + 干燥 + 冷冻的组合，可以在没有盐的情况下延长保存期，但风味和质地会差很多。
  • 注意：不要用海水直接腌肉（含水量高、杂菌多），必须先制盐。

9.6 雪窖

  1. 选背阴、积雪厚、排水好的坡地。
  2. 挖一个深 1–1.5 m 的坑，底部铺树枝。
  3. 放入食物（用布、皮包好，防串味）。
  4. 顶部盖木板、树枝，再覆 30 cm 以上雪。
  5. 留一个可开启的小口，用雪块做门，取用后立即封回。
  6. 做标记，防止被雪埋后找不到。

雪窖的温度比地表稳定，通常在 −5 到 −15 °C，适合短期储存蔬菜、肉类，不适合长期冻存（温度不够低）。

9.7 油脂保存

  • 炼油：把动物脂肪切小块，小火慢熬，滤掉杂质，装入干燥容器。
  • 密封：油面高于肉块，隔绝空气。冷却后形成保护层。
  • 避光、低温。光和热会加速氧化。
  • 哈喇味 = 氧化。不建议食用，但可以当灯油、润滑剂、防水涂层。
  • 骨髓：敲开长骨取骨髓，高脂肪高热量，可直接煮汤或涂抹在食物上。

9.8 变质识别

信号含义处理
酸味、腐臭味细菌繁殖丢弃，不要"煮一下试试"
表面黏滑、拉丝细菌膜丢弃
颜色发绿、发灰、发黑氧化或霉菌丢弃（霉菌毒素耐高温）
包装胀气厌氧菌产气（可能肉毒）绝对不要打开食用
发霉（谷物、坚果）黄曲霉毒素整批丢弃，不能只切掉发霉部分

一条铁律

有疑问，就丢掉。在断网、无医疗的条件下，一次食物中毒可能是致命的。你损失的是几天的热量，赌上的是命。这条规则没有例外。

10急救：在没有医生的地方

目标不是"治好"，是"不让情况变得更糟，并争取到能被救治的时间"。分清这两件事，能救很多人。

先明确边界

本章内容用于现场应急，不替代诊断与处方。任何情况下，只要还存在接触专业医疗的可能，优先转运。不要因为"我读过手册"就延误求助。

10.1 现场处置顺序

  1. 先保证自己安全。触电、塌方、二次雪崩、野兽、交通——救人者变成第二个伤者是最常见的悲剧。
  2. 判断意识与呼吸。拍肩呼喊，观察胸廓起伏 10 秒。无反应无呼吸 → 立即心肺复苏。
  3. 控制大出血。这是唯一能在几十秒内致死的问题，优先于一切。
  4. 处理窒息与胸部伤。清理口腔异物，开放性胸伤用不透气材料覆盖三边（留一边排气）。
  5. 保暖。伤者会迅速失温，即使在"不那么冷"的环境。休克与失温会互相加重。
  6. 固定骨折、处理其他伤。然后才是记录、搬运、求救。

10.2 出血

程度表现处置
毛细血管/小静脉渗血，缓慢干净布直接压迫 5–10 分钟，抬高患肢
静脉/中等动脉持续流出，血色暗红或鲜红用力直接压迫 10 分钟不松手，加厚敷料，绷带加压包扎
大动脉（四肢）喷射状、快速浸透敷料、危及生命直接压迫无效时用止血带，扎在伤口近心端 5–7 cm，记录时间，尽快转运
  • 压迫要持续。反复掀开看"止住没有"会破坏血凝块，是最常见的错误。
  • 敷料被浸透时，不要揭掉，在上面再加一层，继续压。
  • 止血带是"保命不保肢"的手段，只在危及生命时使用。扎上后不要随意松开，记录时间并尽快送医。
  • 不要用绳子、铁丝当止血带（会切割组织）；用宽扁的布带、专用止血带，宽度 5 cm 以上。
  • 不要往伤口里撒泥土、草木灰、面粉——这是感染和破伤风的直通车。

10.3 骨折、脱臼与扭伤

先判断

  • 骨折：畸形、异常活动、骨擦音、剧烈疼痛、迅速肿胀、无法承重。
  • 扭伤：肿胀、疼痛，但无畸形，关节活动受限较轻。
  • 不确定时，按骨折处理。固定不会伤害扭伤，但活动会加重骨折。

夹板固定

  1. 在固定前先检查远端脉搏、颜色、温度、感觉，作为基线。
  2. 用木板、树枝、卷起的杂志、雪鞋做夹板，长度要超过骨折上下两个关节。
  3. 骨突处（踝、膝、肘）垫软物，防止压伤。
  4. 用布条、绳子绑扎，松紧以能塞进一根手指为准。
  5. 固定后每 15 分钟复查远端循环：发白、发紫、麻木、冰凉 → 立刻放松绑带。
  6. 上肢用三角巾悬吊；下肢固定后尽量不要承重。

扭伤：初期（48 小时内）冷敷、抬高、加压、休息。不要热敷、不要揉搓、不要喝酒（加重肿胀）。

10.4 烧伤与烫伤

  • 立即用流动冷水冲 20 分钟。这是唯一被证实能减轻损伤的现场措施。不要用冰水（会加重组织损伤）。
  • 不要涂牙膏、酱油、油、香灰、草药——全部会增加感染、妨碍判断。
  • 不要撕扯粘在伤口上的衣物，剪开周围。
  • 水泡不要挑破（除非在关节处影响活动，且你有无菌条件）。
  • 用干净、不粘的敷料覆盖。没有的话，用保鲜膜、干净塑料袋临时覆盖。
  • 大面积烧伤（超过自己一只手掌面积的 10 倍）会迅速脱水、失温、休克，必须保暖并紧急转运。
  • 面部、手、会阴、关节处的烧伤，即使面积小也要重视。
烧伤最怕的是失温

大面积烧伤后皮肤失去保温能力，冲洗 20 分钟后要立刻擦干、覆盖、保暖。在寒冷环境里，烧伤 + 失温的组合比烧伤本身更致命。

10.5 伤口感染

断网环境下，感染是比外伤更常见的死因。任何伤口，从第一天起就要按"会感染"来管理。

  • 冲洗：用大量干净水（煮沸后放凉）冲洗伤口，冲掉泥沙、碎屑。不要用酒精直接冲进伤口（损伤组织）。
  • 清创：用镊子（火上烧过冷却）取出可见异物。深部异物不要硬拔。
  • 消毒：伤口周围皮肤用碘伏/酒精，伤口内部用生理盐水或干净水。
  • 覆盖：干净敷料，每天更换。敷料湿了、脏了立刻换。
  • 观察：红肿扩大、发热、跳痛、流脓、红线向近心端蔓延、发烧 → 感染扩散，需要抗生素。
  • 脓肿：成熟后（有波动感、局部发热）可考虑切开引流，但必须严格消毒，切开方向避开血管神经。面部"危险三角区"（鼻根到嘴角）的感染绝对不要挤压，可能引发颅内感染。
破伤风

深而窄的刺伤、被泥土/粪便污染的伤口、被生锈金属扎伤，都有破伤风风险。潜伏期 3–21 天，表现为牙关紧闭、苦笑面容、肌肉强直。预防靠疫苗；断网后无法接种，只能靠彻底清创、避免污染伤口。能不打赤脚就不打，能戴手套就戴。

10.6 头部与脊柱

  • 头部外伤后要观察 24–48 小时：意识变化、剧烈头痛、反复呕吐、瞳孔不等大、耳鼻流出血性或清亮液体 → 颅内损伤，必须转运。
  • 不要给头部外伤者服用止痛药掩盖症状（尤其阿司匹林，会增加出血）。
  • 怀疑脊柱损伤（高处坠落、雪崩掩埋、车祸）：不要随意搬动。必须移动时，保持头、颈、躯干成一条直线，多人同步平托。
  • 昏迷但有呼吸：侧卧位（恢复体位），防止舌根后坠和呕吐物窒息。

10.7 冰水溺水

L4：这是极寒场景最快的死法之一

冰水（0–4 °C）中，人在 1 分钟内会因冷休克而过度换气，5–15 分钟内四肢失去力量，30 分钟内可能失温昏迷。生存窗口以分钟计。

如果有人落水

  1. 不要跑过去。冰面已经破了一次，你跑过去会破第二次，变成两个落水者。
  2. 趴下、分散。匍匐靠近，或用长杆、绳子、树枝、围巾从安全距离递过去。
  3. 让对方抓住延伸物，不要直接用手拉（你可能被拽下去）。
  4. 拖上岸后，立刻移到避风处，脱掉湿衣，按失温处置（见 3.7）。
  5. 不要让人站立行走（重度失温时站立可能诱发心脏骤停），用担架或拖拽。

如果自己落水

  • 控制呼吸。冷休克的前 30 秒最危险，强迫自己缓慢深呼吸，不要惊慌挣扎。
  • 不要脱衣服。衣服能提供浮力和保温（湿衣贴身在水中反而减少对流）。
  • 手臂搭上冰面，双腿向后踢水，把身体水平推上冰面，然后滚动离开冰洞，不要站起来走。
  • 尽快离开现场，找避风处换干衣。不要在原地"缓一缓"。

10.8 一氧化碳中毒

  • 症状：头痛、头晕、恶心、乏力、胸闷、意识模糊。特征是一组人同时出现类似"感冒"的症状，且在封闭空间内。
  • 处置：立即打开门窗/通风口，把患者移到室外新鲜空气处。解开衣领，保暖。
  • 无呼吸 → 立即心肺复苏。一氧化碳中毒者在低温下可能出现"假死"，不要轻易放弃复苏，持续到专业救援接手。
  • 不要开灯、不要用打火机（如果怀疑燃气泄漏，火花会引发爆炸）。

10.9 腹泻与脱水

断网环境下，腹泻可能来自不洁饮水、变质食物、寄生虫。真正致命的是脱水，不是腹泻本身。

口服补液盐（ORS）简化配方

成分用量说明
干净水1 L必须煮沸或净化过
糖约 6 平勺（18–20 g）白糖、葡萄糖均可；无糖可用蜂蜜替代
盐约半平勺（3 g）宁少勿多，过咸会加重脱水

喝法：少量多次，每次 50–100 mL，每 5–10 分钟一次。呕吐后等 10 分钟再继续。成人每天可能需要 2–3 L。

不要给腹泻者喝白开水"冲一冲"

大量白水会稀释血液中的电解质，可能导致低钠血症（头痛、呕吐、抽搐）。要么喝 ORS，要么在白水里加一点盐和糖。也不能用运动饮料替代（糖分过高、盐分不足）。

10.10 那些"无法处理"的情况

诚实地说，有些病在野外就是无法处理，只能争取时间。识别它们，比乱治更重要。

脑卒中突发面瘫、肢体无力、言语不清、视物障碍侧卧、保持气道通畅、记录发病时间、紧急转运不要喂食喂水、不要自行用药

10.11 药品清单与使用边界

断网后没有医生，药品从"治疗手段"变成"高风险决策"。原则：只用你确切知道用途、剂量、禁忌的药。

类别用途关键边界

  • 不知道剂量，就不要吃。"吃一片应该没事"是最危险的想法。
  • 抗生素不能预防感染。只有确诊或高度怀疑细菌感染时才用，且必须足疗程。
  • 过期药不等于毒药，但药效会下降。优先使用未过期、保存良好的药品；变色、潮解、胶囊粘连的药不要用。

10.12 必须放弃现场处置、立即转运的信号

  • 意识不清、昏迷、抽搐
  • 呼吸困难、口唇发紫、呼吸停止
  • 大出血无法止住
  • 胸痛、剧烈腹痛、腹部板硬
  • 高热不退、寒战、意识模糊
  • 骨折畸形无法复位、肢体发白/发紫/无感觉
  • 重度失温（寒战停止、意识改变）
  • 头部外伤后意识恶化

在这些情况下，"再观察一下"通常等于放弃。做出转运决定越早，生存概率越高。

11导航与求救：让自己被找到

在野外，最危险的不是不知道自己在哪，而是没人知道你在哪。求救的优先级高于找路。

11.1 没有 GPS 怎么确定方向

影子法（最可靠，无需工具）

  1. 在平坦地面插一根直杆（约 1 m），或在雪地上踩一个点。
  2. 标记此刻影子的尖端（T1）。
  3. 等待 15–20 分钟，影子移动后，标记新的尖端（T2）。
  4. T1 到 T2 的连线指向东（北半球）。垂直于此线、指向远离杆的方向是北。

正午前后影子移动最快，误差最小。这种方法在南北半球都成立，只是方向相反，需要自行判断所在半球。

北极星（北半球夜间）

  • 找到北斗七星，把勺口两颗星（天璇、天枢）连线，向勺口方向延长约 5 倍距离，就是北极星。
  • 北极星几乎正北，误差小于 1°。它不亮，但位置稳定。
  • 南半球没有北极星，可用南十字座的长轴延长约 4.5 倍找到南天极。

不要依赖的方法

  • 树木年轮/枝叶朝向：受地形、光照、风影响极大，只能做参考，不能作为决策依据。
  • 雪堆形状：背风面凹、迎风面陡，但风向会变，雪堆也会变形。
  • 手表指针法：需要地方时和正确的时区修正，误差大。有指南针就不要用。

11.2 离线地图的正确用法

  • 提前下载多级缩放。只下载"全省"级别，放大到街道就是空白。要逐级放大并平移，让缓存覆盖你要走的路线。
  • 标出关键点。水源、避难点、道路交叉口、村落、信号点，用坐标记在纸上。
  • 不要只存在一个设备里。手机 + 纸质打印 + 手绘简图。
  • GPS 定位后立刻记录。打开定位 → 记下坐标 → 关闭定位。不要让它常开。
  • 用等高线判断地形。等高线密集 = 陡坡；V 形指向高处 = 山谷；闭合圈 = 山顶或洼地。

11.5 手机求救的现实

  • 无 SIM 卡也能拨紧急号码（如 120、110、911），但必须有可用基站信号。
  • 全球断网的场景下，基站通常也已失效。所以不要把所有希望放在手机上，物理信号才是主力。
  • 如果还有微弱信号：发短信比打电话成功率高（占用带宽小，可重试）。短信内容要包含：位置坐标、人数、伤情、剩余物资、下一步计划。
  • 省电策略：不要一直开机搜信号。固定时间开机（如每小时开机 2 分钟），发送一条短信后立刻关机。
  • 紧急呼叫的定位：部分地区的紧急呼叫会自动上报粗略位置，但不要依赖。

11.6 留下痕迹

  • 折枝标记：在岔路口折弯树枝，指向你去的方向。
  • 石堆/雪堆：在显眼处堆三块石头或雪块，是国际通用的"此处有人"标记。
  • 布条：在树枝上系鲜艳布条，每隔几十米一个。
  • 刻痕：在树干、岩石上刻箭头和日期。
  • 写信息：在营地留下纸条/刻字：人数、时间、去向、身体状况。
一个反直觉的忠告

如果你已经发出求救信号，并且知道搜救正在进行，最好的策略往往是留在原地。移动会让搜救队不断扑空，也会让你偏离已知路线。只有在原地确实无法生存（没有水、没有柴、庇护所无法搭建）时，才考虑转移，并留下明确的去向信息。

工具的价值不在于精良，而在于"在你需要的时候，它能用"。

12.2 刀的维护与替代

  • 保持干燥。用完擦干，涂一层薄油（动物油也可）。
  • 不要砍骨头、不要撬、不要当凿子用。折刀尤其容易断轴。
  • 磨刀：用平整的石头（砂岩、河卵石），保持 20° 角，单向推磨。不要来回拉锯。
  • 替代：碎玻璃、锋利石片、金属片、罐头铁皮。都能切割，但都更容易伤手，务必小心。

12.4 雪鞋

没有雪鞋，人在深雪里每走一步都陷到膝盖，体力消耗是平时的 2–3 倍。

  1. 选一根有弹性的枝条（柳、桦、榛），弯成椭圆框，长约 60–80 cm、宽 25–30 cm。
  2. 两端绑扎固定，中间加 2–3 根横档。
  3. 用绳索、树皮纤维在框内编成网状，网格 5–8 cm。
  4. 前端略翘起（用火烤弯），便于滑行。
  5. 用布条或皮带做绑带，固定脚掌中部，脚跟可活动。

临时替代：把树枝捆成束踩在脚下，或用睡垫裁成椭圆绑在鞋底。效果差，但比没有强。

12.5 雪橇与拖运

  • 简易拖板：两块长木条 + 横档，前端用绳系成 V 形牵引。
  • 布拖：把物资包在防水布/兽皮里，四角收拢，用绳牵引。适合轻载。
  • 负重原则：不超过体重的 1/3；重心低、靠后；上坡用短绳，下坡用长绳。
  • 雪橇底：涂动物油或蜡，减少摩擦。

12.6 护目与面罩

  • 窄缝护目：硬纸板、树皮、皮革开一条 2–3 mm 的水平缝，绑在脸上。能挡紫外线、防风、防雪粒。
  • 面罩：布、围巾、兽皮。注意呼出的水汽会结冰，要定期抖掉。
  • 不要用深色镜片（如墨镜）在阴天/夜间使用，会看不清地形。用透明或黄色镜片更安全。

12.7 缝补

  • 针：骨针、别针、鱼骨、铁丝。没有针时，用细枝 + 胶带做"临时缝合"。
  • 线：筋腱（最结实）、牙线、尼龙绳拆股、植物纤维。
  • 缝法：回针缝最牢固；帐篷破口用平针 + 内外双层补丁。
  • 防水：缝线处涂松脂、蜡、动物油。

13卫生与疾病预防

在野外，一次腹泻可能让你失去三天行动能力；一次脚部感染可能让你走不出雪地。卫生不是讲究，是战斗力。

13.1 战壕足：极寒环境的隐形杀手

战壕足（trench foot）是长时间潮湿 + 寒冷造成的非冻伤性损伤，不是冻伤，但同样可以导致截肢。

  • 早期：脚趾发白、发麻、肿胀、走路像踩棉花。
  • 进展：发紫、起泡、剧痛、溃烂。
  • 预防：每天换干袜；睡前彻底擦干脚；不要穿太紧的鞋；每 2 小时活动脚趾。
  • 处置：脱鞋、擦干、保暖、抬高。不要按摩、不要热敷、不要刺破水泡。
每天必须做的一件事

睡前脱鞋检查双脚。看颜色、摸温度、按脚趾。冻伤和战壕足在早期都是"不疼"的，等疼的时候已经晚了。这个动作花 30 秒，可能保住你的脚。

13.2 个人清洁

  • 重点部位：手、腋下、腹股沟、脚。用湿布擦拭，不需要全身洗澡。
  • 雪擦身是错的。雪会带走热量、损伤皮肤。用干布或微湿的布。
  • 手卫生：饭前、处理食物前、如厕后。没有肥皂时，用干净水冲洗 + 搓手 30 秒；灰、沙可辅助去污，但不能杀菌。
  • 口腔：用布包手指擦拭牙齿；盐水漱口；柳枝咬软当牙刷。
  • 头发：长发扎紧，减少虱子和打结。

13.3 排泄物处理

  1. 选离水源至少 60 m、离营地 30 m 以上的下风处。
  2. 挖一个 20–30 cm 深的坑（雪地要挖到地面）。
  3. 使用后覆土/覆雪，插一根树枝做标记。
  4. 纸巾烧掉或带走；不要留在野外。
  5. 便后洗手，或用消毒湿巾。
  6. 所有人使用同一个固定厕所，不要随地。

13.4 垃圾与气味

  • 食物残渣会招来动物。所有食物残渣、油脂、包装，装袋挂在高处（离地 2 m、离树干 1 m），或远离营地掩埋。
  • 不要在有食物的地方睡觉。食物气味会吸引熊、狼、野猪。
  • 垃圾不要烧（塑料产生有毒气体），带走或深埋。
  • 血衣、处理猎物的残渣要远离营地，深埋或焚烧。

13.5 女性卫生

  • 布垫可重复使用，用后煮沸消毒并彻底晒干/烘干。
  • 经期要格外注意保暖和补水，失温风险更高。
  • 不要用雪擦拭，不要用未消毒的布。
  • 痛经时热敷下腹，减少活动。

13.6 虱子、疥疮与真菌

  • 虱子：衣物煮沸、暴晒、冷冻（−15 °C 以下数天）。剃除毛发是最彻底的办法。
  • 疥疮：剧烈瘙痒，夜间加重，指缝、腕部、腹股沟有隧道状皮疹。衣物高温清洗，密切接触者同时处理。
  • 脚气/真菌：保持干燥，每天换袜，鞋内撒干土/木炭粉吸湿。不要与他人共用鞋袜。

13.7 水与食物相关疾病

14危险识别：会杀死你的那些事

极寒环境的危险有个共同特点：它们在你意识到之前就已经发生了。所以重点不是"应对"，是"提前避开"。

14.1 雪崩

风险因素说明
坡度 30–45°最危险区间。低于 25° 很少发生，高于 50° 雪不易堆积
背风坡风把雪吹到背风面堆积成"雪檐"，结构不稳
新雪后 24–48 小时新雪层与旧雪层结合不牢
气温骤升 / 降雨融水润滑雪层，极易触发
雪面出现裂缝、闷响"whumpf"声是雪层崩塌的明确信号，立即撤离
凸坡、沟槽雪在此处受张力，最易断裂

通过雪崩地形

  • 一人一次通过，其他人观察。
  • 走脊线、走凸起处，不要走沟底。
  • 解开背包肩带、松开雪崩气囊（如有）、手持雪崩探杆。
  • 观察逃生路线：万一发生，往哪里跑。
  • 不要在雪檐上行走（听到空洞声立刻后退）。

被埋后

  • 用手在口鼻前撑出空间，避免被雪堵住呼吸道。
  • 保持冷静，减少氧气消耗。
  • 如果能动，朝上方挖；如果不能，保存体力，等待救援。
  • 被埋 15 分钟后生存率急剧下降，同伴救援是唯一希望。

14.2 白毛风与暴风雪

  • 白毛风（whiteout）：能见度接近零，天地不分，人会失去方向感，绕圈行走。
  • 应对：立即停止移动，就地挖雪洞或雪壕。绝对不要继续走。
  • 标记方向：在雪洞里放一根伸出的杆子，出口方向用绳子标记。
  • 等待：暴风雪通常持续数小时到数天。保存体力、减少外出。

14.3 雪檐与裂缝

  • 雪檐：山脊背风侧伸出的雪块，看起来像实地，踩上去会整体断裂。听到空洞声、看到裂缝，立刻后退。
  • 冰裂缝：冰川、雪桥下有暗裂缝。结组行进，绳距 10–15 m，随时探路。
  • 雪桥：横跨裂缝的雪层，可能很薄。用登山杖/木棍试探，不要跳。

14.4 冰面与落水

  • 冰厚判断：静水 10–15 cm 可承单人；流动水需要更厚且不均匀；雪覆盖的冰最难判断。
  • 危险信号：冰色发白、蜂窝状、有裂缝、岸边有水渗出、听见"咔咔"声。
  • 通过：结伴、系绳、分散、匍匐、带长杆。
  • 落水自救：见 10.7。

14.5 野兽

动物正确应对绝对不要
熊（黑熊/棕熊）缓慢后退、说话、让自己显得大；不要挡它的退路；带幼崽的母熊最危险不要跑（会触发追逐）、不要爬树（黑熊会爬）、不要装死（除非棕熊已接触且无法脱身）
狼面对它、后退、挥动大物件、保持站立不要转身跑、不要蹲下
野猪爬上高处或树、横向闪避不要直线跑（猪比人快）
驼鹿/鹿绕开、保持距离，尤其发情期不要靠近拍照
蛇静止、缓慢后退，不要惊扰不要挑逗、不要抓
食物与动物

在熊活动区，食物必须悬挂在离地 2 m、离树干 1 m 的位置，或装在防熊罐里。食物气味会吸引动物进入营地，这是人兽冲突最常见的原因。不要在帐篷里存放食物。

14.6 一氧化碳与火灾

  • 一氧化碳：见 10.8。任何封闭空间用火都要通风。
  • 帐篷火灾：合成材料帐篷遇火会瞬间熔化滴落，比燃烧更危险。帐篷内禁止明火。
  • 森林火灾：干燥季节、大风天不要生火；离开前彻底熄灭。

14.7 其他环境危险

  • 枯树/倒木：雪压、风吹会突然倒下。不要在孤立枯树下扎营。
  • 落石：陡坡下方、冻融交替的岩壁。通过时快速、安静、不并行。
  • 冰柱：屋檐、岩壁下的巨大冰柱会突然坠落。
  • 雪崩堆积区：即使没有新雪，堆积区的雪也可能二次移动。
  • 河流冰面：春季融冰期，河边看似结实，中间可能已经空了。

15心理与团队：撑过第三周

大多数野外死亡事件里，人的判断失误比环境因素更致命。而判断力，是被恐惧、疲劳和孤独一点点吃掉的。

15.1 常见的心理崩溃路径

阶段表现危险
否认"很快就会有人来"不做长期准备，浪费前 72 小时的黄金窗口
愤怒/争执互相指责、争夺决策权团队分裂，最致命
讨价还价"再走一小时就到"在错误方向上耗尽体力
抑郁不说话、不吃饭、不参与被团队忽视，逐渐失温/脱水
接受冷静、按计划行动这是目标状态

15.2 恐慌的即时处理

  1. 停下来，坐下。恐慌时人是站不住的，坐下能立刻降低生理唤醒。
  2. 呼吸控制：吸气 4 秒、屏息 4 秒、呼气 6 秒，重复 10 次。延长呼气能激活副交感神经。
  3. 说出五样东西。"我看到……我听到……我摸到……"把注意力从想象拉回现实。
  4. 做一件小事。整理背包、烧一壶水、检查鞋带。行动能重建控制感。
  5. 不要在这时做重大决定。等 10 分钟，再做判断。

15.3 决策疲劳

  • 固定流程：把每天的动作变成清单（起床 → 检查脚 → 烧水 → 记录 → 分配任务），减少"要决定什么"。
  • 减少选项：不要问"今天吃什么"，问"吃 A 还是 B"。
  • 把重要决定放在上午。人在下午和傍晚的判断力最差。
  • 写下来。把决定和理由写在纸上，避免反复推翻。

15.4 团队分工

角色职责轮换
队长最终决策、对外沟通、时间管理不轮换，但需被监督
水/火取水、净水、维持火种每日轮换
食物配给、烹饪、储存每日轮换
警戒夜间守夜、观察动物/天气每 2 小时轮换
记录日志、物资盘点、信号记录固定一人
医疗检查脚、伤口、体温固定一人（或有基础者）

分工不是为了效率，是为了让每个人都有"我还在起作用"的感觉。无用感比饥饿更快摧毁人。

15.5 冲突处理

  • 规则前置：在平静时约定决策规则（队长最终决定、重大事项投票）。
  • 轮流发言：每人说 2 分钟，不打断。很多冲突源于"没被听见"。
  • 对事不对人：讨论"这个方案的风险"，而不是"你总是出错"。
  • 允许退出：有人想单独行动时，明确告知风险，但不强行控制（控制会激化冲突）。
  • 事后复盘：每天花 5 分钟，说一件做得好的、一件要改的。

15.6 时间感与"希望工程"

  • 记录日期。失去时间感是心理崩溃的早期信号。每天在木片刻一道，或在纸上写日期。
  • 建立仪式。每天固定时间烧水、吃饭、检查装备。仪式提供结构感。
  • 小目标。"今天搭好挡风墙""明天多存 5 升水"。完成小目标能维持动力。
  • 讲未来。讨论"出去以后要做什么"。这不是逃避，是维持希望的必要手段。
  • 照顾弱者。让最虚弱的人做力所能及的事（整理、看火），比让他躺着更有帮助。
一个真实的观察

长期生存案例中，活下来的人往往不是最强壮的，而是有明确任务、有同伴、相信还有意义的人。体力决定你能走多远，心理决定你愿不愿意走。

16长期生存：从熬过三天到熬过三个月

前三天的关键词是"保温"，三个月后的关键词是"系统"：稳定的水、稳定的热量、稳定的卫生、稳定的秩序。

长期生存的真正瓶颈

不是打猎技巧，是热量密度和燃料可持续性。一公顷寒带森林能提供的柴火有限，一群人在同一地点烧三个月会把周边砍空。定居点的选址，本质上是燃料半径的选址。

16.2 能源

  • 柴：主要能源。优先收集枯立木、倒木，不要砍活树（湿、难烧、破坏长期资源）。
  • 脂肪灯：动物油 + 苔藓/布条灯芯，可提供微弱照明和一点热量。注意通风。
  • 太阳能：冬天效率低，但可用于给头灯、手电充电。板子要正对太阳、随时清雪。
  • 电池：一次性电池是消耗品，按"最后手段"管理。
  • 火种保存：炭 + 灰 + 密闭容器，能让火种延续数天，省去反复取火。

16.3 定居点选择

16.4 储藏系统

  • 分区：干粮、冻肉、燃料、工具分开存放，避免串味、污染、火灾。
  • 离地：木架、石台，防潮防鼠。
  • 防动物：悬挂、石压、深埋。熊能掀开大多数简易容器。
  • 标记：刻日期和内容。没有标签的储备等于没有储备。
  • 轮换：先存先吃，定期检查。

16.5 卫生系统

  • 厕所：固定位置、远离水源、每日覆土。
  • 垃圾：分类，食物残渣深埋，塑料带走。
  • 洗漱：固定区域，废水不倒回水源。
  • 尸体/猎物残骸：远离营地深埋，防止疾病和动物。

16.6 农业的极限

极寒环境不适合常规农业，但在有季节的地方可以尝试：

  • 作物选择：土豆、芜菁、大麦、黑麦、荞麦。生长期短、耐寒。
  • 无霜期：必须确认当地无霜期长度，否则颗粒无收。
  • 温室：用透明塑料、玻璃、甚至冰砖（冰屋温室）延长生长期。
  • 储备种子：第一年就要留种，不要全部吃掉。
  • 现实预期：第一年产量通常很低，不要指望靠它过冬。

16.7 社区与秩序

  • 规模：15–50 人的群体在长期生存中效率最高（分工可行、冲突可控）。
  • 规则：明确资源分配、劳动分工、冲突仲裁。口头规则不够，要写在木板上公示。
  • 交换：技能、物资、劳动力的交换，比货币更可靠。
  • 外来者：善意但谨慎。先隔离观察，再决定是否接纳。
  • 卫生隔离：有人生病时，餐具、睡眠区分开。

16.8 知识传承

  • 纸质优先。把关键知识抄在布、皮、木片上，防水防火。
  • 口传 + 实操。让年轻人跟着做，而不是只讲。肌肉记忆比文字更持久。
  • 记录失败。失败的原因比成功的经验更有价值。
  • 建立"手册"。把本手册的核心章节抄下来，加上本地特有的知识（水源、植物、天气规律）。

16.9 当设备最终熄灭

手机会在某个时刻彻底没电，或者摔坏、进水、冻裂。在那之前，你要完成三件事：

  1. 把关键知识转成非电子形式。急救、净水、生火、信号、植物识别，至少这五项要有纸质/刻记备份。
  2. 把地图转成手绘。标出水源、避难点、道路、危险区。手绘图比屏幕更可靠。
  3. 把技能转成人。教会至少一个同伴，让知识不依赖任何单一载体。
最后一句实用建议

设备是工具，不是依靠。真正让你活下来的，是你已经练过的动作和你身边愿意合作的人。在还有电的时候，把这两样准备好。

A一页速查（建议打印）

这一页假设你只剩 30 秒。把它打印出来，装进自封袋，放在背包最外层。

失温

  • 寒战停止 = 恶化，不是好转
  • 脱湿衣 → 隔地 → 裹保温层
  • 加温：颈、腋下、腹股沟
  • 清醒可吞咽：温热糖水
  • 禁：搓手脚、喝酒、剧烈运动、烤火
  • 重度：水平搬运，避免颠簸

冻伤

  • 温水 37–39 °C，泡 20–30 分钟
  • 水泡不刺破，不复冻
  • 禁：雪搓、摩擦、火烤、热水袋直贴
  • 必须走远路时：宁可冻着走，不要复温后再冻

净水

  • 煮沸 1 分钟（2000 m 以上 3 分钟）
  • 先布滤 → 静置 → 煮沸
  • 冰比雪省燃料：1 L 冰≈0.9 L 水
  • 松散雪约 10:1，最不划算
  • 禁：海水、尿、血、酒、吃雪

生火

  • 先备足柴，再点火
  • 雪地必须搭平台（离雪 10–15 cm）
  • 引火物 → 细柴 → 中柴 → 粗柴
  • 湿柴劈开取芯 / 做羽毛棒
  • 星形火最省柴，适合过夜

求救

  • 三堆火 / 三短三长三短
  • 反光镜对飞机晃动
  • 地面大字符：V=求助，X=医疗
  • 鲜艳布铺雪地
  • 留字条：人数、时间、去向

一氧化碳

  • 头痛、恶心、想睡 = 危险信号
  • 立即通风，转移到室外
  • 无呼吸 → 心肺复苏，不要轻易放弃
  • 帐篷内禁用炭火/燃气
