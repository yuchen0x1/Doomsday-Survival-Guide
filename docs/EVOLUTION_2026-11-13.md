## 1. 项目认知与功能地图

产品定位为离线优先的中文生存百科和家庭应急工具。当前可读取的工作区包含 React 19 / Vite 8 / Tailwind 4 / Zustand 5 / idb 8 Web 应用、TypeScript core、knowledge-data 数据包和 Capacitor 移动壳。运行时个人数据使用 IndexedDB；知识编译进前端；PWA 通过 Workbox 缓存构建资产。

README 中的 NestJS / Prisma / PostgreSQL API 和 Tauri 桌面源码，在本工作区实际缺失，不能根据历史文档认定它们可运行。Git 恢复后也显示这些路径原本已经缺失。

备份上限 25 MiB / 100000 条；拒绝重复主键、非法日期/坐标/数量以及无效嵌套结构。未知 settings 键保留，兼容已有离线包副本。备份未加密，包含个人资料。CSV 对公式前缀转义。过期库存不会自动报废或扣减，需用户核实；不提供食物安全判断。

视觉沿用现有主题：石墨 `#0b0d0c`、面板 `#141814`、军绿 `#6b8f5e`、卡其 `#c9a961`、危险红 `#d84a3b`、正文 `#e8eae4`；中文系统字体与等宽数量。保留统计区，新增左对齐搜索/排序工具区和可导出的补货列表，手机下换行。没有新增装饰性大图、外部字体或运行时依赖。
